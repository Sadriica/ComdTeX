# ComdTeX

A **Markdown + LaTeX** editor for mathematics and science.

Open a file from the tree on the left, or press Ctrl+P to find one. Every
vault has a `comdtex.md` with a live example of each feature: theorems,
numbered equations, shorthands such as frac(1, n) and sqrt(2), data tables,
plots, diagrams, citations and the computational biology tools.

If you deleted it, run **Restore example files** from the command palette
(Ctrl+Shift+P) to get a fresh copy.

$$sum(n=1, \infty) frac(1, sup(n, 2)) = frac(sup(\pi, 2), 6)$$

The full guide is at https://comdtex.witara.site/docs
