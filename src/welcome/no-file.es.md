# ComdTeX

Un editor de **Markdown + LaTeX** para matemáticas y ciencias.

Abre un archivo desde el árbol de la izquierda, o pulsa Ctrl+P para buscarlo.
Cada vault tiene un `comdtex.md` con un ejemplo vivo de cada función:
teoremas, ecuaciones numeradas, shorthands como frac(1, n) y sqrt(2), tablas
de datos, gráficas, diagramas, citas y las herramientas de biología
computacional.

Si lo borraste, ejecuta **Restaurar archivos de ejemplo** desde la paleta de
comandos (Ctrl+Shift+P) para tener una copia nueva.

$$sum(n=1, \infty) frac(1, sup(n, 2)) = frac(sup(\pi, 2), 6)$$

La guía completa está en https://comdtex.witara.site/docs
